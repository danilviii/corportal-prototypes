# Прототип заявок корпоративного портала

Кликабельный HTML-прототип GP-3129. Демонстрационные данные сохраняются только в браузере через localStorage. Подключения к API портала и реальной отправки писем нет.

Опубликован на GitHub Pages: https://danilviii.github.io/corportal-prototypes/#/requests/mine

## Структура

Статика без сборки: GitHub Pages отдаёт файлы из корня ветки `main` как есть.

- `index.html` — разметка-оболочка и порядок подключения стилей и скриптов.
- `css/` — стили по разделам, `fonts/` — шрифт Inter (woff2).
- `js/` — код прототипа, обычные (не модульные) скрипты с общей глобальной областью. Порядок подключения в `index.html` важен: данные и хелперы раньше страниц, `12-events.js` последним — он запускает первый `render()`.

Маршрутизация на hash (`#/requests/...`), поэтому пути к файлам относительные и прототип работает из любого подкаталога.

Окно «Новая заявка» открывается поверх текущей страницы, шаг хранится в параметре `new`:

- `?new=1` — выбор проекта;
- `?new=<id проекта>` — выбор типа в проекте;
- `?new=<id типа>` — сразу форма. Прямая ссылка для чат-бота: `#/requests/mine?new=t1`, под окном — «Мои заявки».

Старые ссылки `#/requests/new?type=<id типа>` перенаправляются на `#/requests/mine?new=<id типа>`.

## Локальный запуск

```sh
python3 -m http.server 8080
```

Открыть http://localhost:8080/#/requests/mine
